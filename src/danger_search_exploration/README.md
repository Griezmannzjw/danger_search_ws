# danger_search_exploration

未知环境自主探索规划模块。

## 职责

1. 基于栅格地图检测前沿点（已探索与未探索区域的边界）
2. 评估并选择最优探索目标点
3. 向导航模块下发目标点
4. 判断探索完成条件，触发返航

## 当前状态

**骨架版本**：随机游走占位实现，仅用于框架联调。
正式版本需要实现前沿点探索算法。

## 配置参数

见 `config/default.yaml`，主要包括：
- 探索策略选择
- 前沿点最小尺寸
- 重规划间隔
- 覆盖率阈值
- 返航点坐标

## 升级路线

### 前沿点探索（Frontier-based Exploration）
标准实现流程：
1. **前沿点检测**：对占据栅格地图做边缘检测，找出已探索-未探索边界
2. **前沿点聚类**：将相邻前沿栅格聚合成前沿区域
3. **目标评估**：综合考虑距离、信息增益、可达性打分
4. **目标选择**：选择最优前沿点下发给导航

### 可选优化策略
- **分区探索**：将地图分区，按区域顺序探索
- **覆盖路径规划**：类似扫地机器人的覆盖式搜索
- **主动感知**：偏向危险源可能出现的区域（房间内部）

## 与导航模块的边界

- **探索模块**：决定"去哪里探索"（目标点决策）
- **导航模块**：决定"怎么过去"（路径规划与跟踪）
- 接口：`/danger_search/exploration_goal` (PoseStamped)
